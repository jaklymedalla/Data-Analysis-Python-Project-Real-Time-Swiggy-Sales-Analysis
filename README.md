# Data-Analysis-Python-Project-Real-Time-Swiggy-Sales-Analysis
This Python data analysis project performs Exploratory Data Analysis (EDA) and behavioral visualization on real-time Swiggy sales datasets. It leverages Pandas and NumPy to clean raw transactional information, engineering time-series features like monthly revenue milestones, daily performance cycles reindexed from Monday to Sunday, and highly optimized weekly intervals. To elevate the visual appeal of time-strained charts, the pipeline converts cluttered, overlapping date-range blocks into clean, sequential X-axis labels spanning from "Week 1" onward. Using regex keyword mapping, the project separates food orders into distinct Veg vs. Non-Veg food categories directly from item names to analyze consumer habits. The analytical findings are rendered through a blend of static Matplotlib visualizations and interactive Plotly horizontal bar charts that isolate geographical distribution trends by isolating top revenue-generating locations.
